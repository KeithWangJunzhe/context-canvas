## Reading rule / 阅读规则

When implementation and product documents disagree, treat the running code and the latest user-confirmed decision as the current truth, then update the relevant document. Do not use the roadmap as a promise; it is a prioritization tool.

如果实现和产品文档出现不一致，以当前代码和用户最近确认的决定为准，然后补更新相关文档。Roadmap 是优先级工具，不是对外承诺。
